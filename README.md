# 2D Alien Invasion

A 2D space shooter game built with Python and Pygame, featuring multiple stages, power-ups, and a miniboss.

## Requirements

- Python 3.7 or higher
- [pygame](https://www.pygame.org/) library

## Installation

1. **Clone the repository** (or download and extract the ZIP):

   ```bash
   git clone https://github.com/NaNi17899/2D-Aline-Invasion.git
   cd 2D-Aline-Invasion
   ```

2. **Install the required dependency**:

   ```bash
   pip install pygame
   ```

## How to Run

Run the game from the repository directory:

```bash
python "finalone all combine.py"
```

> **Note:** All game assets (images and audio) are loaded from the same directory as the script, so make sure to run the command from inside the cloned/downloaded folder.

## How to Play

| Key | Action |
|-----|--------|
| ← / → Arrow Keys | Move the player left / right |
| Spacebar | Shoot |

### Power-ups

| Power-up | Effect |
|----------|--------|
| 🩹 Heal | Restores player health |
| ❄️ Freeze | Temporarily freezes all aliens |
| 🔫 Double | Enables double bullets |
| 🤝 Assistant | Spawns a helper ship |

### Objective

- Destroy all alien waves to advance through stages.
- Every few stages a **Miniboss** appears — defeat it to proceed.
- The game ends when the player's health reaches zero.

## Assets

All image and audio assets are included in the repository root alongside the game script.
